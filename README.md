# FlashBar 闪烁提醒

一个单文件、零依赖的 Windows 托盘小工具。当后台程序请求关注（任务栏图标闪烁）时，在当前屏幕底部弹出橙色胶囊提醒。

## 有什么用？

隐藏原生任务栏或使用第三方 Dock 后，往往会错过后台窗口的闪烁提醒。FlashBar 监听系统的 `HSHELL_FLASH` 通知，在**鼠标所在显示器**底部中央显示提醒胶囊（随鼠标跨屏切换，延迟约 1 秒）。

| 状态 | 交互与行为 |
| :--- | :--- |
| **新提醒** | 展开 8 秒，显示程序图标、名称与窗口标题；多条待处理时右侧显示 `+N` |
| **8 秒后** | 自动收起为底部细橙线（点击穿透）；鼠标悬停重新展开，移开 2 秒后收起 |
| **左键点击** | 激活并切换到该窗口，同时移出列表（仅展开态可点击） |
| **右键点击** | 忽略当前提醒 |
| **全屏场景** | 观看全屏视频、游戏或演示时自动隐藏胶囊（提醒在托盘继续累计），退出后恢复 |
| **自动消除** | 手动切到目标窗口、或目标窗口关闭后提醒自动消失；闪烁停止本身不会消除提醒 |

## 适合谁用？

- **第三方 Dock 用户（如 Seelen UI）**：替代原生任务栏后，用来接管后台程序提醒。无需额外设置，胶囊会自动避让贴底的 Seelen Dock。
- **原生任务栏自动隐藏用户**：搭配[配套 Windhawk 模组](#进阶配置可选)使用，可防止后台程序闪烁时强行弹出任务栏。
- **多显示器用户**：提醒始终出现在鼠标当前所在的屏幕，无需手动配置。

> **系统要求**：Windows 10 / 11 (x64)，内置 .NET Framework 4.x（无需额外安装运行库）。

## 如何使用？

### 快速开始

1. 下载并双击运行 `FlashBar.exe`（单实例运行，启动后在系统托盘显示橙色圆点及未读计数）。
2. **托盘交互**：
   - **左键单击**：重新展开胶囊 8 秒（有待处理提醒时）。
   - **右键菜单**：支持触发「测试提醒」、开关「开机自启」、「实验功能」（[接管系统通知](#实验功能接管系统通知)）以及「退出」。
3. **命令行演示**：运行 `FlashBar.exe --demo` 可立即触发一次测试提醒。

### 进阶配置（可选）

- **屏蔽原生任务栏闪烁（Windhawk 模组）**  
  如果你保留了原生任务栏并开启了自动隐藏，建议安装仓库内的 [`windhawk/taskbar-ignore-flash.wh.cpp`](windhawk/taskbar-ignore-flash.wh.cpp)。它会拦截任务栏的 `HSHELL_FLASH` 通知，让原生任务栏不再因闪烁而弹出，提醒完全交给 FlashBar。
- **支持切换管理员权限窗口**  
  受限于 Windows 权限隔离，普通权限的 FlashBar 无法激活以管理员身份运行的窗口。如需支持，请勿勾选托盘的「开机自启」，改用**管理员终端**创建最高权限计划任务（将路径替换为实际位置）：
  ```bat
  schtasks /create /tn "FlashBar" /tr "D:\Tools\FlashBar\FlashBar.exe" /sc onlogon /rl highest /f
  ```
- **收纳托盘图标**  
  在 Windows「设置 → 个性化 → 任务栏 → 其他系统托盘图标」中关闭 FlashBar，可将其收入溢出菜单，不影响正常弹窗。

### 实验功能：接管系统通知

托盘右键 →「实验功能」→ 勾选「接管系统通知」后，FlashBar 会读取通知中心里新到的通知（应用自己发的 Toast 和经 WNS 推送来的通知最终都进通知中心），用同一个胶囊显示，并关掉这些应用的系统横幅——相当于在「设置 → 系统 → 通知 → 某应用」里关掉「显示通知横幅」。通知本身照常进入通知中心，历史记录和通知上的按钮都还在那里。

| 场景 | 行为 |
| :--- | :--- |
| **新通知** | 与闪烁提醒一样展开 8 秒，显示「应用名 · 标题：正文」，之后收成细线 |
| **左键点击** | 切到该应用已打开的窗口；没有窗口就从开始菜单启动它；都不行则打开通知中心 |
| **右键点击** | 只从胶囊移除，通知中心里的原通知保留 |
| **自动消除** | 在通知中心点掉 / 清除了这条通知，或之后切到了该应用，胶囊里的这条随之消失 |
| **既闪烁又发通知** | 同一应用的闪烁并入它的通知，只显示一条 |

- **首次开启**：若提示没有权限，到「设置 → 隐私和安全性 → 通知」打开通知访问权限后再勾选。开启时通知中心里已有通知的应用立即接管，其余应用在第一次来通知后接管（这一条的系统横幅可能还会弹一次）。
- **已接管的应用**：子菜单列出接管过的应用。取消勾选即「交还系统」：恢复它的系统横幅，FlashBar 不再显示它。本来就关了横幅的应用默认不接管；系统组件（自动播放、蓝牙、Windows 更新、安全中心等）和「时钟」的闹钟始终交给 Windows。
- **发送测试通知**：以 Windows PowerShell 的身份发一条通知，用来确认效果。
- **还原**：关闭本功能、退出或注销时，FlashBar 改过的横幅设置全部还原；若异常退出，下次启动会按 `%LOCALAPPDATA%\FlashBar\toast-apps.txt` 里的备份自动对账。

> **注意**：横幅被接管后，通知上的按钮（快速回复、接听来电、闹钟稍后提醒等）只能在通知中心里操作；胶囊左键只能打开应用，无法定位到那条消息。Teams、手机连接等需要接听来电的应用，建议在「已接管的应用」里取消勾选。读取其他应用的通知（`UserNotificationListener`）对非打包程序并非微软正式支持的用法，只能每 0.5 秒轮询，后续 Windows 更新可能改变行为；出错时菜单会标注并自动还原横幅。按应用关横幅依据的是 Windows 11 的设置项，Windows 10 上未验证。

### 编译与自测

仓库包含完整源码（`src/`）及一键脚本，依赖系统自带的 `csc.exe`，无需安装 Visual Studio：

```bat
:: 1. 编译（需先退出正在运行的 FlashBar）
build.bat

:: 2. 自动化自测（需先启动 FlashBar.exe）
powershell -ExecutionPolicy Bypass -File test_flash.ps1 -Seconds 3

:: 3. 实验功能自测（需先在托盘开启「接管系统通知」）
powershell -ExecutionPolicy Bypass -File test_toast.ps1
```

运行日志保存在 `%LOCALAPPDATA%\FlashBar\flashbar.log`（上限 512KB，自动轮转）；同目录还有设置 `settings.ini` 和实验功能的横幅备份 `toast-apps.txt`。日志只记录通知来自哪个应用，不记录通知内容。

## 卸载与限制

### 卸载

1. 若开启过开机自启，请先在托盘菜单中取消勾选（或删除注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 下的 `FlashBar` 项）。
2. 右键托盘图标选择「退出」（开启过「接管系统通知」的话，退出时会把各应用的通知横幅还原）。
3. 直接删除程序目录及 `%LOCALAPPDATA%\FlashBar` 日志目录即可。

### 已知限制

- **过滤规则**：仅捕获可见窗口（含最小化窗口）的闪烁，自动忽略隐藏后台窗口；同一窗口 15 秒内的重复闪烁视为同一次提醒；右键忽略的窗口在本轮闪烁结束前不会再次弹出。
- **全屏判定**：仅针对独占全屏、演示模式或严格铺满当前屏幕的前台窗口生效，无边框窗口化全屏不触发隐藏。
- **防打扰机制**：胶囊不走 Windows 通知中心，系统「勿扰模式」对其无效（接管来的系统通知同样如此）。
